# Setup checklist

Do this once, before the first application wave. Nothing here goes into
the shared skill; it lives in your private setup.

## 1. Define your tracks

A track is one job family with its own resume, identity, and counter.

- Primary track: [TRACK NAME, e.g. Data Scientist]
- Interim tracks: [TRACK NAMES, e.g. Support, Operations, UX/UI]

For each track, record:

- Email used for applications: [EMAIL]
- LinkedIn profile URL: [URL] (one per track, never mixed)
- Resume builder or file: [PATH]
- Counter start: [NUMBER] (each track counts separately)

## 2. Fill in your kit

The kit is what goes into every recruiter reply. Fill every field with
a truthful value or leave it out; never invent one.

- Full name: [NAME]
- Phone: [PHONE]
- Availability window: [DAYS + TIMES + TIMEZONE]
- Work authorization wording: [EXACT WORDING, e.g. "authorized to work in the US without sponsorship"]
- Location for forms: [CITY, STATE]
- Current employer + title (for application history, never removed): [EMPLOYER, TITLE]
- Salary rule per track:
  - Primary track: [STATE TARGET PROACTIVELY / FLEXIBLE]
  - Other tracks: [NEVER NAME A NUMBER / WORK WITHIN BUDGETED RANGE]
- Portfolio URL rule: [ON RESUMES AND FORMS ONLY / NEVER IN MESSAGES]

## 3. Fill in your standing answers

One row per question type, truthful values only:

- Years per skill: [SKILL: YEARS, one line each, never compressed into one sentence]
- Years of experience (general): [NUMBER]
- Data engineering / pipelines: [YEARS]
- Start date: [ASAP / DATE]
- Relocate: [YES / NO]
- Travel: [YES / NO]
- References: [available on request]
- Driver's license: [YES / NO]
- Education: [DEGREE, SCHOOL, DATES]

## 4. Set up your registry

Create the campaign registry file (see `references/tracking.md`).
It holds two lists: submitted and skipped. Every session reconciles
both counts before anything else moves.

## 5. Set your approval preferences

- Batch approvals once per application wave, not per upload.
- Recruiter replies send without per-reply approval (see hold rules in
  `references/recruiter-kit.md`).
- Cold outreach emails need human review before sending.
- Human-hands tasks: sign-ins, taps, in-app deletes, bookings,
  CAPTCHA loops that fail once, RTR signatures, ID documents.

## 6. Set your schedules (suggested)

- Blitz sessions: as often as your capacity allows; each starts with
  the Indeed digest.
- Recruiter inbox sweep: every 2 to 3 hours during the day.
- LinkedIn inbox watch: every 3 hours.
- Follow-up pass: weekly, same-week rule applies (see SKILL.md).
- Interview prep: the moment a booking lands, not the day before.
